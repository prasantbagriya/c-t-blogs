           SMART WORKFLOW AUTOMATION ENGINE - DOCUMENTATION
========================================================================

Project Overview:
A high-performance, visual workflow builder for WhatsApp and Web automation,
built with a "Dual-Trigger" philosophy and a premium, flat UI design.

------------------------------------------------------------------------
1. THE DUAL-TRIGGER PHILOSOPHY (LOGIC A & B)
------------------------------------------------------------------------

The engine is built around two primary entry points:

LOGIC A: INBOUND (User-Initiated)
- Trigger: A customer sends a message or interacts first.
- Scope: FAQ automation, Keyword responses, Service inquiries.
- Goal: Immediate automated assistance.

LOGIC B: OUTBOUND (System-Initiated)
- Trigger: An external event (e.g., Website Form Submit, New Order in CRM).
- Scope: Proactive notifications, Order updates, Lead follow-ups.
- Goal: Automated reach-out using Meta-approved templates.

------------------------------------------------------------------------
2. ADVANCED TRIGGER ENGINE (THE ENTRY POINT)
------------------------------------------------------------------------

The "Inbound Trigger" is now an all-inclusive detection system:

A. INPUT TYPES SUPPORTED:
- Text & Emojis (Any combination)
- Symbols & Special Characters (!@#$%^&*()_+)
- Media (Images, Videos, Documents, Audio/Voice Notes)
- Location & Contact cards

B. MATCHING LOGIC:
- Match ANY Word (OR): Triggers if any one keyword is found.
- Match ALL Words (AND): Triggers only if the full set of words is present.
- Exclude Words (NOT): Negative keywords to prevent triggering.

C. MATCH TYPES (SMART PROCESSING):
- Exact Match: Message must match exactly.
- Contains Word: Triggers if keyword exists anywhere in a sentence.
- Smart Match (WhatsApp Special): Automatically ignores emojis AND 
  symbols (!@#$%^&*) attached to the word (e.g., "hii👋!!!" matches "hii").
- Case-Insensitivity: All matching is case-insensitive ("Hi" = "hi").

------------------------------------------------------------------------
3. INTERACTIVE NODE LIBRARY
------------------------------------------------------------------------

A. WHATSAPP MESSAGE NODE:
- Supports up to 3 Interactive Buttons.
- Each button has its own output handle for branching logic.

B. WHATSAPP LIST NODE:
- Supports menu-style lists (up to 10 rows).
- Perfect for "Select Department" or "Service Menus".
- Each row acts as a conditional branch.

C. META TEMPLATE NODE:
- Supports Meta-approved templates.
- Includes a "Variables/Params" section to inject dynamic data (e.g., User Name).

D. CATALOG NODE:
- Integrated with WhatsApp E-commerce.
- Send product categories or specific items directly.

------------------------------------------------------------------------
4. LOGIC & SERVICE NODES
------------------------------------------------------------------------

- CONDITION NODE: Dual-branching (TRUE/FALSE) based on message content.
- WAIT NODE: Smart delays (Minutes/Hours/Days) for follow-up flows.
- MCP NODE: Connects to AI, SQL Databases, or CRMs (Fetch/Update actions).
- HANDOFF NODE: Instantly transfers the chat to a Human Agent dashboard.

------------------------------------------------------------------------
5. UI & DESIGN STANDARDS
------------------------------------------------------------------------

- THEME: Sleek Dark/Light mode with high-contrast slate palettes.
- AESTHETICS: No Shadows, Flat Borders, Regular weights (Professional look).
- MOBILE: Responsive pop-ups and info tooltips for every feature.
- DENSITY: High-density sidebar and grid views for fast workflow design.
